# Turtle Crossing Game

## Overview

The **Turtle Crossing Game** is a fun Python project built using the `turtle` module. Inspired by the classic arcade game *Frogger*, the goal is to help the turtle safely cross a busy road without getting hit by moving cars.

## How to Play

- Use the **Up Arrow Key** to move the turtle forward.
- Avoid getting hit by the moving cars.
- If the turtle reaches the top safely, the game advances to the next level.
- Each level increases the difficulty by making cars move faster.
- If the turtle collides with a car, the game resets.

## Features

- **Randomly generated cars** that move at varying speeds.
- **Level progression**, where the game gets harder with each successful crossing.
- **Simple and fun gameplay** using Python’s `turtle` graphics.

## Installation & Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/bsdivith/Turtle-Crossing-Game.git
   cd Turtle-Crossing-Game
   ```
2. **Install Python (if not installed)**:
   - Download and install [Python](https://www.python.org/downloads/).
3. **Run the Game**:
   ```bash
   python main.py
   ```

## Dependencies

- Python 3+
- `turtle` (built-in module, no additional installation required)
- `random`
- `time`

## Customization

- **Adjust Car Speed**: Modify the `MOVE_INCREMENT` variable in `cars.py` to change difficulty.
- **Change Turtle Speed**: Adjust `tortoise.py` settings for movement speed.
- **Modify Colors**: Customize car colors in `cars.py`.
